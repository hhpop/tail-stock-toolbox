# 尾盘选股工具箱 · 10合1

基于东方财富 JSONP 接口的浏览器端尾盘选股工具，**无需后端**，直接拉取全市场 A 股实时行情。

## ✨ 功能

- 🎯 **10 大尾盘策略**：主力净流入 / 放量突破 / 温和上涨 / 资金驱动 / 抢筹 / 量价齐升 / 低换手强势 / 中小市值活跃 / 低振幅蓄势 / 冲高试盘
- 🚫 **红线淘汰**：ST、跌停、流动性不足、换手异常、市值过小等 8 条硬规则
- 📊 **动态评分**：涨幅 / 量比 / 资金 / 换手 / 涨速 五维加权
- 🔄 **自动刷新**：每分钟自动更新行情
- 📱 **响应式布局**：手机 / 平板 / 桌面自适应
